# SmartMall Mobile

Expo mobile application for iOS and Android, connected to the SmartMall Laravel API.

## Development

From the repository root:

    pnpm install
    pnpm --dir mobile start

The app uses the Expo managed workflow. Native iOS and Android folders are generated by Expo/EAS and are intentionally not committed.

## Included

- Customer authentication, malls, products, search, scanner, cart, checkout, orders, delivery, and notifications
- Staff POS screens
- Arabic/English RTL support
- Optional store and product metadata foundation for future grocery and butcher support

Existing backend contracts and checkout payloads remain unchanged.
